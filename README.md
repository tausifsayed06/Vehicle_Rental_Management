# DriveEase - Vehicle Rental Service Project

Full-Stack College Project (Node.js + Express + MongoDB + HTML/CSS/JS)

## How to Run the Project:

1. Extract the Zip file.
2. Open terminal/command prompt inside the project folder.
3. Run `npm install` to install required packages (Express, Mongoose, Cors).
4. Run `npm start` to start the backend server.
5. Open your browser and go to: `http://localhost:5000`

## Features:
- Frontend UI with Vehicle Filter (Cars & Bikes)
- Full Backend Integration (User Register, Login & Credentials Storage)
- Vehicle Booking Requests Saved directly to Database
- Admin Data endpoint: `http://localhost:5000/api/admin/data`
